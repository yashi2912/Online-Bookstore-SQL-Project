# 📚 Online Bookstore SQL Project

A complete SQL data analysis project on an Online Bookstore using **PostgreSQL & pgAdmin 4**.

### 🔗 Live Project: [https://github.com/yashi2912/Online-Bookstore-SQL-Project]

### 🛠️ Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

### 📁 Project Structure
- `sqlproject1.sql` - Complete SQL queries (Table creation + 20 business questions)
- `03_Books.csv` - Books data (500 rows)
- `04_Orders.csv` - Orders data
- `05_Customers.csv` - Customers data

### 📊 Business Problems Solved
1.  Retrieve all books in Fiction genre
2.  Find books published after 1950
3.  List customers from Canada
4.  Show orders placed in November 2023
5.  Find total stock of books
6.  Calculate remaining stock (Stock - Order Quantity)
7.  Find the most expensive and cheapest book
8.  Find customers who spent more than $100

### 💡 Key Learnings
- Solved `COPY FROM` file permission errors by using `\copy` and Import/Export tool
- Used `ILIKE` for case-insensitive filtering
- Implemented JOINs, GROUP BY, ORDER BY, Aggregations for business insights

### ▶️ How to Run This Project
1. Create database `ONLINE_BOOKS_STORE` in pgAdmin
2. Run `sqlproject1.sql` to create tables
3. Import CSV files using Import/Export Tool
